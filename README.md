# Berth

Ground infrastructure for autonomous drones. This repo holds the one-page Berth website.

- `index.html` is the whole site: styles, the interactive station drawing, charts and copy in one file. It needs no build step.
- To view it locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
- Before sharing, replace the placeholder contact address (`CONTACT_EMAIL` near the top of the script).

Figures marked as Berth targets or estimates are internal planning numbers. Market figures are cited in the page footer under Sources.
